# CLIPPER - Downloads

## Instalar

Abra a pagina Releases.
Baixe o CLIPPER-Setup-<versao>.exe mais recente.
Execute e siga o assistente (instala o VST3 em `C:\Program Files\Common Files\VST3`).
Abra a DAW, faca um rescan de plugins e carregue CLIPPER no canal desejado.

## Requisitos

Windows 10/11, 64 bits.
DAW com suporte a VST3.

## Como usar

Ajuste o knob CLIP para controlar picos e saturacao. O knob MIX ajusta a mistura
dry/wet. A waveform e o status indicam o nivel de picos.

Mais detalhes, limitacoes e roteiro de fases estao no README do projeto principal.
